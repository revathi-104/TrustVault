# Prompts Used — TrustVault

## Project
TrustVault — Secure Document Sharing with a Real Audit Trail

## AI Assistance
AI assistance was used during development to help plan the application structure, implement features, troubleshoot errors, and prepare documentation.

## Main Tasks and Prompts

### 1. Project Setup
"Help me build a Flask-based secure document-sharing application with user authentication, document uploads, and an audit trail."

### 2. Database Design
"Design SQLAlchemy models for users, documents, document sharing permissions, and audit logs."

### 3. Authentication and Authorization
"Implement user registration, login, logout, and role-based access control for normal users and administrators."

### 4. Document Management
"Implement document uploads, authorized downloads, document sharing with registered users, and permission revocation."

### 5. Integrity Verification
"Use SHA-256 hashing to verify whether a downloaded document matches its saved integrity hash."

### 6. Audit Logging
"Record important events such as login, document upload, sharing, download, and integrity verification."

### 7. Testing and Troubleshooting
"Help me test document sharing, file downloads, integrity verification, and administrator-only page access."

### 8. Documentation
"Prepare project documentation explaining the application features, technology stack, local setup, and security limitations."

## Human Verification
The application was manually tested for login, document sharing, downloads, SHA-256 integrity verification, and admin access control. Results were checked in the local application.
