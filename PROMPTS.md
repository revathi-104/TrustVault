# TrustVault — AI Prompts Documentation

## 1. Project Planning
**Prompt:** Help me plan a secure document-sharing web application called TrustVault with user authentication, role-based access control, document sharing, file integrity verification, and audit logs.

## 2. Application Development
**Prompt:** Help me build a Flask web application using Flask-SQLAlchemy, HTML, CSS, and SQLite. Organize the application into understandable routes, database models, templates, and static files.

## 3. User Authentication
**Prompt:** Help implement user registration, login, logout, and password hashing in Flask. Validate login credentials securely and manage user sessions appropriately.

## 4. Role-Based Access Control
**Prompt:** Help implement administrator access control so that only an authorized administrator can access the admin dashboard. Explain how to configure the administrator account safely.

## 5. Document Management
**Prompt:** Help implement document upload and download functionality in Flask. Restrict document access to authorized users and handle uploaded files safely.

## 6. Document Integrity Verification
**Prompt:** Help implement SHA-256 hashing to calculate a document's hash and verify whether the document's contents have changed.

## 7. Document Sharing
**Prompt:** Help implement document sharing between registered users, including access checks and the ability to revoke a user's access to a shared document.

## 8. Audit Logging
**Prompt:** Help create audit logs for important actions such as login, document upload, download, sharing, and access-related operations. Display relevant audit activity on the administrator dashboard.

## 9. Debugging and Deployment
**Prompt:** Help troubleshoot Flask application errors, verify application behavior, manage environment variables, configure dependencies, and prepare the application for deployment on Render.

## 10. Documentation and Final Verification
**Prompt:** Help prepare a README.md describing the project's purpose, features, technology stack, local setup instructions, live demo, testing status, and known limitations. Provide a final checklist for verifying the GitHub repository and deployed application.

## Note on AI Assistance
AI assistance was used to support project planning, implementation guidance, debugging, and documentation. The application was manually tested for core workflows, including login, document upload and download, SHA-256 integrity verification, document sharing, and administrator access.

This document summarizes the categories of prompts used during development. It is not intended to represent an exact transcript of every prompt or conversation.
